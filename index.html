      10

      Compte Valorant

      Connecte ton compte pour importer automatiquement tes dernières parties. Tes identifiants (clé API, pseudo, tag) restent enregistrés uniquement dans ce navigateur — ils ne sont jamais partagés avec les autres visiteurs du site, même si vous utilisez le même lien. Chaque personne doit saisir ses propres identifiants.

      Comment trouver ces informations ?

      Clé API HenrikDev

      1. Rejoins le Discord HenrikDev : discord.com/invite/X3GaVkX2YN
      2. Dans le salon dédié à la génération de clé, choisis « VALORANT (Basic Key) » dans le menu déroulant du bot.
      3. Le bot affiche immédiatement une clé (une longue chaîne de caractères) : copie-la et colle-la dans le champ « Clé API HenrikDev » ci-dessus.
      4. Tu peux la retrouver plus tard sur api.henrikdev.xyz/dashboard en te connectant avec le même compte Discord.

      Pseudo Riot et Tag

      1. Ouvre le client Valorant (ou le launcher Riot).
      2. En haut à droite, à côté de ton nom, ton Riot ID complet s'affiche sous la forme TonPseudo#1234.
      3. Tout ce qui précède le # va dans « Pseudo Riot ».
      4. Tout ce qui suit le # (sans le #) va dans « Tag ».

      Exemple : pour le Riot ID Henrik3#EUW3, mets Henrik3 dans Pseudo et EUW3 dans Tag.
